# KRATOS PLAYER — documentos legales

Páginas legales de la aplicación **KRATOS PLAYER**, un reproductor multimedia para Smart TV,
publicado por **KRATOS TV**.

- [Política de privacidad / Privacy Policy](https://osmaredriel-cell.github.io/kratosplayer/privacy.html)
- [Términos de uso / Terms of Use](https://osmaredriel-cell.github.io/kratosplayer/terms.html)
- [Reporte de infracción / DMCA](https://osmaredriel-cell.github.io/kratosplayer/dmca.html)

La aplicación es únicamente un reproductor: no incluye ni distribuye canales, listas,
suscripciones ni contenido. El usuario aporta su propio servicio.

Las páginas se generan desde el repositorio de la aplicación:
`node scripts/legal-build.js osmaredriel-cell.github.io/kratosplayer soporte@kratostv.com "KRATOS PLAYER"`
y se sube el contenido de `build/legal/`.
